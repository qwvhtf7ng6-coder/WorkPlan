## 2024-05-18 - Avoid repeated filtering inside loops
**Learning:** When calculating stats that require mapping over a collection (like departments) and matching against another collection (like requests), pre-filtering the dataset outside the main loop by common invariants (e.g. by year) significantly reduces loop overhead. Furthermore, replacing iterative array methods (`flatMap`, `filter`) and repeated parsing inside those nested loops with a single-pass loop dramatically lowers memory overhead.
**Action:** When working on complex data aggregations and reports, pre-filter datasets to extract invariants outside mapping loops, and use single-pass `for` loops inside to accumulate counters and update arrays simultaneously, dropping the Big O complexity by an order of magnitude.
